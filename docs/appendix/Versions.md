# 版本与兼容性

## 文档对应版本

| 项目 | 值 |
| ------------ | ------------------------- |
| 文档对应模组 | OmniMorph `1.0.0-alpha.12` |
| Minecraft | 26.1.2 |
| 模组加载器 | Fabric |
| Java | 25 |
| 文档语言 | 简体中文 |

版本或代码更新后，本页应同步更新。

## 兼容性说明

- Figura 形象、脚本与大部分 API 继续可用。
- YSM 模型的支持范围取决于模型格式与当前构建。
- 云端功能取决于后端协议与能力开关。

## 状态标记

| 标记 | 含义 |
| -------- | -------------------------------------- |
| 稳定 | 当前版本可用 |
| 预览 | 功能存在，但界面或行为可能变化 |
| 依赖后端 | 需要兼容后端与相应能力开关 |
| 2.0 占位 | 界面存在但业务尚未实现 |
